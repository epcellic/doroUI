# 整体说明：
本项目为自己按照日常硬件使用需求进行开发集成的一个小UI项目，基于stm32及oled屏幕，用来各种调取以及复用，是很棒的整合项目，包含了例如数字信号读取及图形化显示，AD模拟量读取，模拟量转电压值，串口投屏，游戏等等功能。


# 引脚说明：
共四个按键：PC6-PC9分别为 PC6 确定/进入/继续 PC7 后退/暂停/关闭 PC8 左 PC9 右
AD通道配置引脚PA0 PB0 PC0 数字信号收集引脚即PC6确定键 oled屏幕占用： PB6PB7用于oled供电（PB6--GND PB7--VCC） PB8PB9用于IIC通信(PB8--SCL PB9--SDA) 按键5 PC13用于数字波形的低电平触发 按键6 PC14用于数字波形的高电平触发
串口专用引脚：PA9(TX)--RX PA10(RX)--TX
